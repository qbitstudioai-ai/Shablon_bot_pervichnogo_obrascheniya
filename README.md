# Шаблон бота первичного обращения

Это репозиторий с архитектурой, правилами и будущим кодом шаблона. Шаблон нужен, чтобы быстро создавать бота первичного обращения для новой компании без проектирования системы с нуля.

## Что входит в систему

- клиентский бот, который общается с потенциальными клиентами;
- n8n, где выполняется логика диалога и интеграций;
- Supabase, где хранятся переписки, состояния диалогов, метрики и база знаний;
- дашборд руководителя;
- отдельный служебный Telegram-бот каждой компании для загрузки базы знаний и получения технических уведомлений.

У каждой компании свои Telegram-боты, токены, Credentials n8n и отдельная schema Supabase, например **kompaniya_001**. Данные разных компаний не смешиваются.

## Главный принцип разработки

Сначала решение подробно фиксируется в документации. Затем создаются таблицы Supabase и workflow n8n. После проверки создаётся дашборд.

ChatGPT руководит проектом и проверяет результат. Куратор принимает решения и выполняет действия, требующие ручного доступа. VSCode используется для разработки дашборда, локальной работы с файлами и отправки проверенных изменений в GitHub.
