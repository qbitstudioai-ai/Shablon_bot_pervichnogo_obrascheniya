# План 1. Создание эталонного шаблона

## Назначение

Этот план используется при разработке самого продукта. Он не описывает внедрение в конкретную компанию.

Правила:

- выполняем один небольшой блок за раз;
- зависимые шаги не объединяем;
- пункт отмечается `[x]` только после проверки результата;
- после каждого блока обновляется `docs/PROJECT_STATE.md`;
- секреты не сохраняются в репозитории.
