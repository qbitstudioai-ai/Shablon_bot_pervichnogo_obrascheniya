# Как запускать SQL проекта в Supabase

Короткая памятка для Павла. Она нужна, чтобы не запускать устаревшую версию файла и не потерять важную диагностику при ошибке.

## Перед запуском

1. Открыть нужный SQL-файл заново в ветке `main` GitHub. Не использовать старую вкладку, старую копию или текст из предыдущего сообщения.
2. Проверить первую строку файла: в ней должны совпадать ID и версия задачи, которые указал ChatGPT, например `DB-03E v0.11`.
3. Если ChatGPT дал контрольную строку для поиска, найти её в файле до копирования. Это подтверждает, что открыт именно актуальный вариант.
4. Скопировать **весь файл целиком**. Не собирать SQL из отдельных фрагментов.
5. В Supabase SQL Editor полностью заменить старый текст: `Ctrl+A` → вставить новый полный файл.
6. Перед Run ещё раз проверить заголовок/версию в первой строке редактора.

## Запуск

- Нажать Run один раз и дождаться завершения.
- Не запускать verifier, следующий SQL или исправленный вариант, пока ChatGPT не проверит результат текущего запуска.
- Не менять SQL вручную, даже если причина ошибки кажется очевидной.

## Что прислать ChatGPT

При успехе — весь возвращённый JSON/result без сокращений.

При ошибке — полный текст от `ERROR:` до конца `CONTEXT:`, включая диагностические JSON/поля. Не пересказывать ошибку своими словами.

## Как понимать результат

`applied` означает, что migration дошла до COMMIT и изменения применены. Это ещё не означает, что задача полностью закрыта.

`verified` означает, что отдельный verifier подтвердил ожидаемое состояние после применения migration.

Если migration завершилась ошибкой **до COMMIT** и сам файл прямо гарантирует транзакционный rollback, изменения этой попытки не считаются применёнными. Это утверждение нельзя переносить на любой SQL-файл автоматически — сначала проверяется конкретный файл.

## Безопасность

- Эта памятка не даёт разрешения менять production, удалять рабочие данные или переключать трафик.
- Запускать только тот файл и в той среде, которые явно указаны для текущей задачи.
- Credentials, токены и секреты в SQL не вставлять.
- Если версия файла, среда или ожидаемый результат не совпадают — остановиться и прислать это ChatGPT.
