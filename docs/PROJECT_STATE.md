# Текущее состояние проекта

Дата обновления: 2026-09-19.

## Что уже согласовано

- роли ChatGPT, куратора и VSCode;
- два плана: создание шаблона и внедрение для новой компании;
- отдельная schema Supabase для каждой компании;
- данные диалогов, этапы, целевые события и метрики;
- напоминания через 20 минут и через 24 часа;
- после второго напоминания без ответа пользователь считается потерянным;
- у каждой компании отдельный служебный Telegram-бот со своим токеном;
- служебный workflow жёстко привязан к schema компании;
- формат Markdown и постоянный identifikator_dokumenta;
- правила очистки, чанкинга, embeddings и безопасного обновления;
- понятные транслитерированные имена Supabase и русские описания;
- старые знания архивируются только после успешной проверки новой версии.

## Что создано в документации

- архитектура;
- словарь данных;
- жизненный цикл диалога;
- определения метрик;
- требования к загрузке базы знаний;
- требования к Markdown;
- правила именования;
- шаблон Markdown-файла.

Спроектировать точную SQL-структуру базы знаний:

1. таблицы **dokumenty_znaniy** и **fragmenty_znaniy**;
2. pgvector и размерность выбранной модели;
3. индексы и ограничения уникальности;
4. функцию поиска только по активным данным компании;
5. транзакцию публикации новой версии;
6. grants/RLS и тест запрета доступа к другой schema;
7. контрольные SQL-запросы.

После согласования SQL можно создавать JSON служебного workflow n8n.
