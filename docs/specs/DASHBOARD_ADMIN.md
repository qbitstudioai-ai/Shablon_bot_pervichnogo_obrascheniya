# Дашборд руководителя и админ-панель Павла

## Роли

Руководитель компании просматривает показатели и разрешённые диалоги своей компании. Павел — разработчик/администратор. Админ-панель предназначена только ему; роль проверяется сервером.

Исполнитель разработки — AI-помощник в VSCode по готовой задаче ChatGPT. VSCode как редактор сам по себе задачи не исполняет.

## Первая версия админ-панели

| Возможность | Хранение / правило |
|---|---|
| Название, логотип, цвета, подписи этапов, видимые разделы, период по умолчанию | nastroyki_dashborda; проверенная запись и журнал изменения |
| Часовой пояс отображения | nastroyki_dashborda; меняет группировку отчёта, не сроки уже созданных задач |
| Просмотр доступов руководителей и их отзыв | Серверная авторизация и dostupy_dashborda; безопасная административная операция |
| Просмотр версий шаблона, БД и состояния интеграций | Только чтение паспорта/телеметрии |
| Просмотр документов, активной версии, результатов загрузок | Только чтение; загрузка через служебный Telegram |
| Ошибки, задержки очереди, неизвестные доставки | Просмотр, отметка разбора; разрешение повтора — только после проверки внешнего результата |
| Журнал административных действий | Только чтение, дополнение сервером |

Логотип хранится сервером дашборда в приватном каталоге с выдачей безопасного изображения. Проверяются тип/размер; активный SVG/HTML не исполняется. В БД хранится путь и версия, не произвольный внешний исполняемый контент. Каталог входит в резервное копирование экземпляра.

## Что настраивается вне панели

Поведение бота, системные prompts, список служебных user ID, бизнес-часовой пояс, сроки напоминаний, выбранные каналы/CRM и модели настраиваются в блоке n8n «МЕНЯТЬ ПРИ ВНЕДРЕНИИ». Токены и пароли — в Credentials/серверных секретах.

Полного редактирования логики бота и работы со свободным SQL в панели v1 нет. Это осознанный небольшой первый объём, который Павел сможет расширять отдельными задачами по результатам эксплуатации.

## Применение настроек и проверки

Изменение подписи этапа не меняет его код и не переписывает историю. Изменение часового пояса отображения явно меняет отчётный период; интерфейс показывает используемый пояс. Правила диалога не зависят от цвета или порядка отображения этапов.

Любая запись проверяет роль Павла, допустимые поля и версию настройки, чтобы параллельные изменения не затирали друг друга. Записываются автор, время и безопасное описание изменения.

Проверки: руководитель не может вызвать админ-операцию напрямую; нельзя подменить компанию; секреты отсутствуют в ответах API/браузере; сырые сообщения доступны только разрешённой роли. Подробности — [ACCESS_AND_ISOLATION.md](ACCESS_AND_ISOLATION.md).
